# Лабораторная работа №3 по курсу «Операционные системы»

**Вариант 2** (как в ЛР1). Родительский процесс создаёт дочерний. Первой строкой пользователь вводит имя файла. Далее он вводит строки вида «число число число», которые передаются дочернему процессу. Дочерний процесс считает сумму чисел каждой строки (тип float) и пишет её в файл, а последней строкой — сумму всех чисел.

Обмен данными идёт через именованную разделяемую память POSIX (`shm_open` + `mmap`), синхронизация — через два именованных семафора (`sem_open`). Имена объектов содержат PID родителя, поэтому у каждой пары процессов они свои.

## Сборка (Linux / WSL)

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

Запускать из папки, где лежат обе программы (родитель запускает `./child`):

```bash
cd build
./parent
out.txt
1 2 3
1.5 2.5
```

Ввод заканчивается `Ctrl+D`. Результат:

```bash
cat out.txt
```

## Объекты в общей памяти

Пока программа работает, в другом терминале:

```bash
ls -l /dev/shm
```
